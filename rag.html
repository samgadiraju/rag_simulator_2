1. Create Knowledge Base

This simulates creating a Knowledge Base containing business information.

2. Chunk Generation

Documents are broken into smaller pieces called chunks.

3. Vector Embeddings

Each chunk becomes a numeric vector called an embedding.

4. User Query + Retrieval

The query embedding searches the vector database for the most relevant chunks.

5. LLM Prompt + Response

Retrieved chunks + user query are sent to the LLM as context.
